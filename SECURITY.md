# Меры безопасности сайта

Этот документ описывает все меры безопасности, реализованные для защиты сайта от взлома и атак.

## 🔒 Реализованные меры защиты

### 1. Защита от XSS (Cross-Site Scripting)

- **Санитизация входных данных**: Все пользовательские данные очищаются от потенциально опасных символов
- **Экранирование HTML**: Использование функции `escapeHtml()` для безопасного отображения контента
- **Компоненты SafeContent и SafeText**: Автоматическое экранирование при выводе пользовательских данных
- **Проверка на опасные паттерны**: Обнаружение и блокировка скриптов, iframe, javascript: протоколов

**Файлы:**
- `src/lib/security.ts` - утилиты санитизации
- `src/components/SafeContent.tsx` - безопасные компоненты

### 2. Rate Limiting (Ограничение частоты запросов)

- **Защита форм**: Максимум 3 заявки в минуту с одного email
- **Защита входа**: Максимум 5 попыток входа в 15 минут с одного email
- **Автоматическая очистка**: Устаревшие записи удаляются каждые 5 минут

**Реализация:**
- `loginRateLimiter` - для аутентификации
- `formRateLimiter` - для контактных форм

### 3. Валидация и санитизация данных

- **Email**: Очистка от недопустимых символов, приведение к нижнему регистру
- **Телефон**: Разрешены только цифры, +, пробелы, скобки и дефисы
- **Текст**: Удаление HTML тегов и опасных паттернов
- **Пароли**: Проверка сложности (минимум 8 символов, заглавные/строчные буквы, цифры, символы)

### 4. Защита паролей

- **Минимальная длина**: 8 символов
- **Проверка сложности**: 
  - Заглавные и строчные буквы
  - Цифры
  - Специальные символы
  - Длина 12+ символов даёт бонус
- **Защита от слабых паролей**: Блокировка распространённых паролей (password, 12345678, qwerty и т.д.)
- **Визуальная индикация**: Индикатор силы пароля при регистрации

### 5. Защита админ-панели

- **Двойная проверка прав**: Проверка на клиенте и сервере
- **Валидация UUID**: Проверка формата идентификаторов перед операциями
- **Валидация статусов**: Разрешены только предопределённые значения
- **Подтверждение удаления**: Требуется подтверждение перед удалением данных
- **Безопасный вывод**: Все пользовательские данные экранируются

### 6. HTTP Security Headers

Добавлены в `index.html`:
- `X-Content-Type-Options: nosniff` - предотвращение MIME-sniffing
- `X-Frame-Options: DENY` - защита от clickjacking
- `X-XSS-Protection: 1; mode=block` - встроенная защита браузера от XSS
- `Referrer-Policy: strict-origin-when-cross-origin` - контроль передачи referrer
- `Permissions-Policy` - ограничение доступа к API браузера

### 7. Защита от SQL-инъекций

- **Supabase**: Использование параметризованных запросов через Supabase SDK
- **Row Level Security (RLS)**: Политики безопасности на уровне базы данных
- **Валидация входных данных**: Все данные проверяются перед отправкой в БД

### 8. Защита от CSRF

- **Генерация токенов**: Функция `generateCSRFToken()` для создания безопасных токенов
- **Валидация токенов**: Проверка токенов перед выполнением операций

### 9. Безопасная аутентификация

- **Supabase Auth**: Использование проверенной системы аутентификации
- **Хранение сессий**: Безопасное хранение в localStorage с автоматическим обновлением токенов
- **Проверка прав**: Проверка ролей пользователей на сервере

## 📋 Рекомендации по дальнейшей защите

### На уровне сервера (Supabase)

1. **Настройте RLS политики** в базе данных для дополнительной защиты
2. **Включите логирование** подозрительной активности
3. **Настройте rate limiting** на уровне Supabase Edge Functions
4. **Используйте HTTPS** для всех соединений

### На уровне приложения

1. **Регулярно обновляйте зависимости**: `npm audit` и `npm update`
2. **Мониторинг**: Настройте отслеживание подозрительной активности
3. **Резервное копирование**: Регулярные бэкапы базы данных
4. **Логирование**: Ведите логи всех операций в админ-панели

### Дополнительные меры

1. **2FA (двухфакторная аутентификация)**: Для администраторов
2. **IP whitelist**: Ограничение доступа к админ-панели по IP
3. **CAPTCHA**: Для форм обратной связи (при необходимости)
4. **WAF (Web Application Firewall)**: На уровне хостинга/CDN
